# ChemConcentration Lab 🧪
### เว็บแอปพลิเคชันคำนวณและจำลองความเข้มข้นสารละลายสำหรับนักเรียน

เว็บแอปพลิเคชันสื่อการเรียนรู้วิทยาศาสตร์เชิงโต้ตอบ (Interactive Learning) พัฒนาด้วย **HTML5 + Tailwind CSS + Vanilla JavaScript** เพื่อช่วยให้นักเรียนระดับมัธยมศึกษาเข้าใจการคำนวณความเข้มข้นของสารละลายอย่างเป็นรูปธรรม พร้อมภาพจำลองบีกเกอร์เสมือนจริงที่เปลี่ยนแปลงระดับของเหลว ความเข้มของสี และความหนาแน่นของอนุภาคสารแบบ Real-time

---

## ✨ ฟีเจอร์หลัก (Key Features)

1. **คำนวณความเข้มข้นครบทั้ง 3 รูปแบบมาตรฐาน (% Concentration)**:
   - **%w/w (ร้อยละโดยมวลต่อมวล):** สูตร $\frac{\text{มวลตัวละลาย (g)}}{\text{มวลสารละลาย (g)}} \times 100\%$
   - **%w/v (ร้อยละโดยมวลต่อปริมาตร):** สูตร $\frac{\text{มวลตัวละลาย (g)}}{\text{ปริมาตรสารละลาย (cm}^3 \text{ หรือ mL)}} \times 100\%$
   - **%v/v (ร้อยละโดยปริมาตรต่อปริมาตร):** สูตร $\frac{\text{ปริมาตรตัวละลาย (mL)}}{\text{ปริมาตรสารละลาย (mL)}} \times 100\%$
2. **โหมดคำนวณ 2 รูปแบบ**:
   - **โหมดคำนวณหาความเข้มข้น (%):** ป้อนปริมาณตัวละลายและตัวทำละลาย/สารละลายรวมเพื่อหาค่าร้อยละ
   - **โหมดเตรียมสารละลาย (Lab Preparation):** กำหนดความเข้มข้นเป้าหมายและปริมาตรที่ต้องการ เพื่อคำนวณหาปริมาณสารที่ต้องชั่งหรือตวง
3. **ภาพจำลองบีกเกอร์เสมือนจริง (Interactive Real-time Beaker Simulation)**:
   - **ระดับของเหลว (Liquid Level):** เพิ่ม-ลดตามปริมาตรรวมของสารละลาย พร้อมขีดสเกลวัดปริมาตร
   - **ความเข้มของสี (Color Intensity):** สีจะจางเมื่อสารละลายเจือจาง และจะเข้มทึบขึ้นเมื่อมีความเข้มข้นสูง
   - **ระบบอนุภาคตัวละลาย (Solute Particles):** จำลองการเคลื่อนที่แบบบราวน์ (Brownian motion) อนุภาคจะหนาแน่นขึ้นตามความเข้มข้น
   - **สารละลายอิ่มตัวและการตกตะกอน (Precipitate):** หากความเข้มข้นสูงเกินจุดอิ่มตัว อนุภาคจะตกตะกอนนอนก้นบีกเกอร์
   - **ปุ่มควบคุมการทดลอง:** ปุ่มคนสารละลาย (Stir), ปุ่มเติมน้ำ (+50 mL) เพื่อเจือจาง, ปุ่มเติมตัวละลาย (+5 g/mL)
4. **สารเคมีจำลองในบทเรียน (Chemical Presets)**:
   - จุนสี ($\text{CuSO}_4$ - สารละลายสีฟ้าใส)
   - ด่างทับทิม ($\text{KMnO}_4$ - สารละลายสีม่วงเข้ม)
   - โพแทสเซียมไดโครเมต ($\text{K}_2\text{Cr}_2\text{O}_7$ - สารละลายสีส้มสด)
   - เกลือแกง ($\text{NaCl}$ - สารละลายใสไม่มีสี)
   - น้ำตาลทราย ($\text{C}_{12}\text{H}_{22}\text{O}_{11}$ - สารละลายใส)
   - เอทานอล/แอลกอฮอล์ ($\text{C}_2\text{H}_5\text{OH}$)
   - สีผสมอาหาร / น้ำหวานเข้มข้น (สีแดง, สีเขียว)
5. **แสดงวิธีทำอย่างละเอียดทีละขั้นตอน (Step-by-Step Breakdown)**:
   - แสดงสูตร แทนค่าตัวเลข ตัดหน่วย และอธิบายความหมายของผลลัพธ์
6. **โหมดฝึกทำโจทย์ (Practice Quiz)**:
   - สุ่มโจทย์คำนวณเคมีจากสถานการณ์จริง พร้อมตรวจคำตอบและแสดงเฉลยทันที
7. **สรุปทฤษฎีและข้อควรระวัง (Knowledge Base)**:
   - สรุปนิยามตัวละลาย ตัวทำละลาย สารละลายอิ่มตัว และการแปลงหน่วย (kg, g, mg, L, mL, cm³)

## 🚀 วิธีการเปิดใช้งาน (How to Run)

เว็บนี้เป็นแบบ Client-Side (SPA) ทำงานได้โดยไม่ต้องติดตั้ง Node.js หรือเซิร์ฟเวอร์ใด ๆ:

1. ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานบนเว็บเบราว์เซอร์ได้ทันที (เช่น Google Chrome, Microsoft Edge, Safari, Firefox)
2. หรือรันผ่าน Live Server / Python Simple HTTP Server:
   ```bash
   python -m http.server 8000
   ```
   แล้วเข้าใช้งานผ่าน `http://localhost:8000`
